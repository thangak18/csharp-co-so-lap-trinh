Chương trình và ngôn ngữ lập trình

Chương trình (program) là tập hợp các câu lệnh được viết theo một ngôn ngữ lập trình, ra lệnh cho máy tính thực hiện một công việc cụ thể.

Ngôn ngữ lập trình là ngôn ngữ có cú pháp chặt chẽ để con người "nói chuyện" với máy tính.

Ví dụ đời thường: công thức nấu ăn là một "chương trình". Đầu bếp (máy tính) làm đúng từng bước, không tự suy diễn.
Cấp độĐặc điểm
Ngôn ngữ máyDãy bit 0/1, máy hiểu trực tiếp, con người khó đọc
Hợp ngữ (Assembly)Dùng từ gợi nhớ: MOV, ADD…
Bậc caoGần ngôn ngữ con người: C#, Java, Python, C++

Máy chỉ hiểu ngôn ngữ máy, nên chương trình bậc cao cần được dịch: biên dịch (compiler: dịch cả chương trình rồi chạy) hoặc thông dịch (interpreter: dịch đến đâu chạy đến đó). C# là ngôn ngữ biên dịch.

Lý thuyết

Quy trình giải bài toán bằng máy tính

  1. Xác định bài toán: đầu vào (Input) là gì? Đầu ra (Output) cần gì?
  2. Thiết kế thuật toán: các bước để biến Input thành Output.
  3. Viết chương trình: chuyển thuật toán thành mã nguồn C#.
  4. Chạy thử và sửa lỗi: kiểm tra với nhiều bộ dữ liệu, kể cả trường hợp đặc biệt.
  5. Hoàn thiện và bảo trì: tối ưu, viết chú thích, cập nhật khi yêu cầu thay đổi.

IOVí dụ xác định bài toán

"Tính diện tích hình chữ nhật"

  • Input: chiều dài a, chiều rộng b (số thực, > 0)
  • Output: diện tích S
  • Xử lý: S = a × b
Lời khuyên: đừng mở Visual Studio ngay. Luôn làm bước 1 và 2 trên giấy trước. Đây là thói quen giúp làm bài thi nhanh và ít sai.

Thuật toán là gì?

Thuật toán (algorithm) là một dãy hữu hạn các bước, được sắp xếp theo trình tự xác định, để từ Input tìm ra Output của bài toán.

1Tính hữu hạn

Phải dừng sau một số bước hữu hạn.

2Tính xác định

Mỗi bước rõ ràng, chỉ có một cách hiểu.

3Tính đúng đắn

Cho kết quả đúng với mọi dữ liệu hợp lệ.

4Tính phổ dụng

Giải được cả lớp bài toán, không chỉ 1 bộ số.

5Tính hiệu quả

Tốn ít thời gian và bộ nhớ nhất có thể.

+Có Input / Output

Nhận dữ liệu vào và cho ra kết quả.

Lý thuyết

C# và .NET là gì?

C# (đọc là "C Sharp") là ngôn ngữ lập trình hiện đại, hướng đối tượng, do Microsoft phát triển (năm 2000, Anders Hejlsberg).

.NET là nền tảng để chạy chương trình C#: cung cấp thư viện có sẵn (nhập/xuất, toán học, chuỗi, tệp…) và môi trường thực thi CLR.

C# dùng để làm gì? Ứng dụng desktop (WinForms, WPF), web (ASP.NET), game (Unity), ứng dụng doanh nghiệp, di động (MAUI).

Chương trình C# chạy như thế nào?

  1. Viết mã nguồn trong tệp .cs
  2. Trình biên dịch dịch sang mã trung gian IL
  3. CLR dịch IL thành mã máy (JIT) và chạy

Nhờ cơ chế này, CLR lo việc quản lý bộ nhớ (thu gom rác, garbage collection) thay cho lập trình viên.

Thực hành

Tạo project Console App trong Visual Studio

  1. Cài Visual Studio Community (miễn phí), chọn workload .NET desktop development.
  2. Mở Visual Studio → Create a new project.
  3. Chọn mẫu Console App (ngôn ngữ C#) → Next.
  4. Đặt tên project, ví dụ Buoi01, chọn thư mục lưu → Next → Create.
  5. Viết code trong Program.cs, nhấn Ctrl + F5 để chạy.

Bài 4.Nâng cao

Vẽ lưu đồ giải phương trình bậc hai ax² + bx + c = 0 (xét đủ các trường hợp, kể cả a = 0).

Xem gợi ý
  • a = 0 → quay về giải PT bậc nhất bx + c = 0.
  • a ≠ 0 → tính Δ = b² − 4ac. Δ < 0: vô nghiệm; Δ = 0: nghiệm kép x = −b/2a; Δ > 0: hai nghiệm x₁,₂ = (−b ± √Δ) / 2a.
