Lý thuyết

Tại sao cần tệp tin?

Biến và mảng nằm trong RAM: tắt chương trình là mất hết. Tệp tin lưu trên ổ đĩa, tồn tại lâu dài.

  • Tệp văn bản (.txt, .csv): mở bằng Notepad đọc được, môn học này chỉ dùng loại này.
  • Tệp nhị phân (.exe, .jpg, .dat): lưu dạng byte.
MaSV,HoTen,GiuaKy,CuoiKy SV001,Nguyen Van An,7.5,8.0 SV002,Tran Thi Binh,6.0,6.0 SV003,Le Minh Chau,9.0,9.5

CSV (Comma-Separated Values): mỗi dòng là một bản ghi, các trường cách nhau bằng dấu phẩy. Excel mở được.

Đường dẫn tệp

File nằm ở đâu? Với đường dẫn tương đối, Visual Studio tìm file trong thư mục bin\Debug\net8.0\ của project. Trong Solution Explorer, chọn file → Properties → Copy to Output Directory: Copy if newer.

Kiểu cấu trúc (struct)

Thay vì nhiều mảng song song, gom các thông tin của một đối tượng vào một kiểu dữ liệu mới.

Lý thuyết

Khai báo và sử dụng struct

  • struct định nghĩa một kiểu dữ liệu mới gồm nhiều trường (field).
  • Khai báo struct bên ngoài class Program (hoặc bên trong, ngang hàng Main).
  • public để truy cập được từ bên ngoài.
  • Truy cập trường bằng dấu chấm: sv.HoTen.

  • using System.IO;; đường dẫn Windows dùng @"...".
  • File.ReadAllLines / WriteAllLines / AppendAllText: nhanh gọn.
  • StreamReader: while ((line = sr.ReadLine()) != null).
  • Luôn dùng khối using để tự đóng file.

  • struct gom các trường của một đối tượng, có thể chứa phương thức.
