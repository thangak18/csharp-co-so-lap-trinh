## Bài tập ôn luyện có chấm tự động

Mỗi buổi có trang `bai-tap-NN.html` gồm:
- Trắc nghiệm đọc code / lần vết (có giải thích).
- Bài lập trình viết code ngay trên web, **Chạy thử** với dữ liệu tự nhập và **Chấm bài** với test case.

Code C# được biên dịch và chạy **ngay trong trình duyệt** bằng trình biên dịch Roslyn chạy trên WebAssembly (thư mục `runner/`, mã nguồn ở `runner-src/`). Không cần máy chủ.

Build lại trình biên dịch (cần .NET SDK 10): `./build-runner.sh`
