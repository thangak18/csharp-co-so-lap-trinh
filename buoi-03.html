Câu lệnh switch…case

  • Biểu thức có kiểu: int, char, string, bool…
  • Mỗi case là một hằng cụ thể, không phải khoảng.
  • Bắt buộc có break cuối mỗi case trong C#.
  • default tương tự else, không bắt buộc.
Lý thuyết

Khi nào dùng if, khi nào dùng switch?

ifDùng if…else if khi

  • Điều kiện là khoảng giá trị: dtb >= 8
  • Kết hợp nhiều biến: a > 0 && b < 0
  • Kiểu số thực double

swDùng switch khi

  • So sánh một biến với nhiều giá trị cụ thể
  • Xây dựng menu chọn chức năng 1, 2, 3…
  • Phân loại theo ký tự, mã: 'A', 'B', "HN", "HCM"

Bài 1.Cơ bản

Nhập 3 số nguyên a, b, c. Tìm và in ra số lớn nhất, số nhỏ nhất.

Xem đáp án
Bài 2.Cơ bản

Nhập điểm hệ 10, quy đổi sang điểm chữ theo thang tín chỉ (ví dụ): A (≥ 8.5), B (7.0–8.4), C (5.5–6.9), D (4.0–5.4), F (< 4.0).

Bài 3.Trung bình

Nhập 3 cạnh a, b, c. Kiểm tra có phải tam giác không; nếu có thì cho biết là tam giác đều, cân, vuông hay thường.

Xem gợi ý
  • Tam giác: a + b > c && a + c > b && b + c > a
  • Đều: a == b && b == c; Cân: a == b || b == c || a == c
  • Vuông: a*a + b*b == c*c || a*a + c*c == b*b || b*b + c*c == a*a
  • Kiểm tra theo thứ tự: không phải tam giác → đều → vuông → cân → thường.

Viết menu: 1. Tính tổng, 2. Tính hiệu, 3. Tính tích, 4. Tính thương. Nhập lựa chọn và 2 số, dùng switch để xử lý.

Bài 6.Nâng cao

Nhập ngày, tháng, năm. Kiểm tra ngày có hợp lệ không, nếu hợp lệ thì in ra ngày kế tiếp (ví dụ 31/12/2024 → 1/1/2025; 28/2/2023 → 1/3/2023).

Xem gợi ý

Tái sử dụng code tính số ngày trong tháng ở ví dụ mẫu 1. Nếu ngay < soNgay → ngày + 1; ngược lại ngày = 1, tháng + 1; nếu tháng > 12 → tháng = 1, năm + 1.

Bài tập về nhà

Chuẩn bị cho buổi 4

  1. Nhập một số nguyên, cho biết số đó dương/âm/bằng 0 và chẵn/lẻ.
  2. Nhập một ký tự, cho biết đó là chữ hoa, chữ thường, chữ số hay ký tự đặc biệt (gợi ý: c >= 'A' && c <= 'Z').
  3. Tính cước taxi: 1 km đầu 15.000đ; từ km 2 đến 30: 12.000đ/km; trên 30 km: 10.000đ/km.
  4. Nhập tháng (1–12), dùng switch in ra quý tương ứng (gộp case).
  5. Nhập điểm 3 môn, tính điểm trung bình và xếp loại; nếu có môn dưới 4 thì xếp loại tối đa là Trung bình.
Tổng kết

Ghi nhớ của buổi 3

  • So sánh: == != > < >= <=; logic: && || !.
  • Khoảng [a, b]: x >= a && x <= b.
  • if…else if…else: kiểm tra từ trên xuống, dừng ở nhánh đúng đầu tiên.
  • Toán tử 3 ngôi: đk ? a : b.
  • switch: so sánh 1 biến với các giá trị cụ thể, mỗi case cần break.
  • Gộp case bằng cách viết liền nhau: case 7: case 8:.
  • Luôn kiểm tra dữ liệu không hợp lệ trước (điểm âm, chia cho 0…).
  • Tự đặt bộ test bao phủ mọi nhánh.
Buổi tiếp theo: Cấu trúc lặp for, while, do…while.
